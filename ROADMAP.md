# Roadmap

Issues planned for the next releases.

## Chart

- [ ] Add an extended-hours toggle for the chart in settings.
- [ ] Draw pre-market and after-hours candles in candlestick mode.

## Search

- [ ] Improve stock search.
- [ ] Show the exchange for each result, and allow searching all markets or
      only one like BVB (stocks ending in `.RO`).

## Settings

- [ ] Move stock search out of its own **Find ticker symbol** page and next
      to the lists in **General**.
- [ ] Put all chart options on one page: some are in **General**, some in
      **Appearance**.
- [ ] Rework the color settings so it is clear how a theme looks and which
      custom colors are allowed.

## Portfolio

- [ ] Separate the global portfolio settings from the ones that only apply
      when adding a single stock.
- [ ] Redesign the holdings list: a single flat list is very hard to read.
